# MyMonday

לוח משימות מקומי וחינמי: משימות מסודרות לפי נושאים, עם סטטוס ותאריך יעד לכל משימה.

## הרצה

צריך [Node.js](https://nodejs.org) בגרסה 18 ומעלה. אין תלויות להתקנה.

```bash
npm start
```

אחר כך פותחים את http://localhost:3000 בדפדפן.

## מה אפשר לעשות

- **נושאים (קבוצות):** ליצור, לשנות שם, לשנות צבע, לכווץ ולהרחיב, ולמחוק.
- **משימות:** להוסיף (מקלידים בשורה "+ הוסף משימה" ולוחצים Enter), לשנות שם ולמחוק.
- **סטטוס:** לא התחיל / בעבודה / תקוע / הושלם. לוחצים על תא הסטטוס ובוחרים מהרשימה.
- **תאריך יעד:** בוחרים תאריך לכל משימה. משימה פתוחה שהתאריך שלה עבר מסומנת "באיחור", ומשימה שהתאריך שלה היום מסומנת "היום".
- **סינון:** חיפוש לפי שם, סינון לפי סטטוס, והסתרת משימות שהושלמו.
- **סרגל סיכום** מתחת לכל נושא, שמראה את חלוקת הסטטוסים.

## איפה הנתונים נשמרים

בקובץ `data/db.json` בתיקיית הפרויקט. הקובץ לא נכנס לגיט, כך שהמשימות שלך נשארות רק אצלך. לגיבוי, פשוט מעתיקים את הקובץ.

השרת מאזין רק ל-localhost, כך שאי אפשר לגשת אליו ממחשבים אחרים ברשת.
